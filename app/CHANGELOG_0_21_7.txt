Independent scan colours
Each point-cloud scan has its own colour button in the Project Explorer and
a Scan colour command in its context menu and Properties. Choose a solid colour,
measured RGB, greyscale/colour intensity, elevation, automatic scan colour, or
follow the global viewer setting. Styles are saved with the project and Undo
restores them. Separate scans can use different styles, including separated
pocket scans. Measured coordinates, intensity, RGB and exported attributes do
not change. Analysis/review colours retain their meaning.

Inspect each matching pocket
In Clean > Find similar shapes, click a match's name to zoom to that object and
load its original measured observations in full-density binary pages. Nearby
measured lining is shown as a separately labelled context sample. Turn selection
highlight off to inspect measured intensity. Previous/Next moves through matches;
Back to matches restores the prior camera and frees the extra graphics buffers.
The view does not tick removal boxes, teach the library or modify source data.
Removal and separation still apply to ALL checked groups in the review.

Whole-cloud matching/selection remains streamed with exact 64-bit original IDs.
The 100,000-point display page size is not a cloud input limit. A 192 MiB local
graphics budget protects the close-up viewer; an oversized compact group reports
that limit instead of claiming a sampled view is complete. Context is sampled.
Cancellation and superseded page requests cannot replace the current view.
